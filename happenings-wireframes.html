Happenings — Page Templates & Wireframes

Three modular wireframes for events on cfbhall.com: two detail-page templates (Full-Service / Transactional for high-impact ticketed events, and Lead Generation & RSVP for non-ticketed / community events) plus a denser Happenings listing. Updated for Nebo r2: full-width image hero (adjustable height + in-header CTAs), flexible date labels, optional Ventrata / form-embed / calendar, FAQ accordion, Facebook Event in the Location / Share sidebar, and share icons Facebook · Instagram · X. Use the module bar on each template to see desktop reflow when optional blocks are off.

  • Chrome (live-matching rail · hours bar · topbar · footer)
  • Optional block — site admin can enable / disable
  • Layout toggle — full-width vs. location/share sidebar
View as designed standalone page (live rail): 1 · Full-Service / Transactional 2 · Lead Gen & RSVP 3 · Happenings Listing

01

Full-Service / Transactional Detail

Target event type: high-impact, ticketed events (game-day parties, premium & fundraising programs, workshops). Goal: move the visitor to purchase fast — above the fold.

Key requirements: full-width image hero (height + in-header CTAs), flexible date labeling, offer copy above Get Tickets, optional Ventrata directly below that section, optional Add to Calendar, FAQ accordion, Facebook Event in the sidebar, configurable share icons. Toggle modules to watch the desktop grid collapse to a single column when Ventrata or the sidebar is empty.

02

Lead Generation & RSVP Detail

Target event type: non-ticketed, informational, or community-centric events (panels, film screenings, free community days, charity drives). Goal: capture sign-ups and RSVPs plus email newsletter sign-ups.

Key requirements: configurable RSVP fields / labels / button text; CTA at the bottom of the form; Save My Spot submits this form (hero/sticky scroll to it). Form embed and Facebook Event are alternatives — never two forms side by side. Facebook Event prefers the Location / Share sidebar.

03

Happenings — Listing Page

Target: the main Happenings listing. Requirement: optimize / reduce the size of event cards so more fit per row and the page scrolls less. No location/share sidebar.

Cards show only the essentials (compact image, date, title, small category tag). Filter categories are CMS-managed in Umbraco (create, edit, reorder). Heading text nav and chip row use the same order: All · Upcoming · Free / RSVP · Ticketed · Exhibitions · Community.
