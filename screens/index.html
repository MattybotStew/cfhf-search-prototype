Import order (html.to.design)

This index is not for Figma. Capture each screen file separately.

Tap an event card is not its own frame — it is the listing (01 or 02 after filter). In Figma, prototype-link each card by event type: ticketed cards → 03; RSVP cards → 06.

Filters (All, Upcoming, Free / RSVP, Ticketed, Exhibitions, Community) are browse-only. Exhibitions and Community can show a mix of ticketed and RSVP cards. Only the event’s published template decides the detail path.

How you import

  1. Serve the repo with a local server, not file:// (example: python3 -m http.server 8080 from repo root).
  2. Open each HTML, then capture at 1440 (*-d.html) or 390 (*-m.html) — one viewport per file.
  3. Photos are local <img> files under screens/img/ (not CSS backgrounds or cfbhall.com URLs — the plugin drops those).
  4. Sticky bars, Ventrata, Maps, and Facebook iframes are drawn as static UI here on purpose.
  5. Kaneda + Neusa (Typekit) often do not embed on import. Swap to Hall Figma text styles after import.
